# 踩坑记录

按出现顺序整理，每条写清现象、根因、处理方式。都是实际遇到过并且改了代码的。

## 一 布局与翻周

### 1. 首屏左侧多出一列邻周，压在节次列上

现象：本周居中时，左上角露出一列周日的表头和网格，和固定节次列的「节次」两个字重叠。

根因：三屏用 flex 横排，`flex-basis` 写百分比。小程序 webview 里百分比 basis 可能按内容宽解析，得到的屏宽和实测轨道宽不一致，平移一屏之后差出一列。

处理：丢掉 flex 横排，三屏改绝对定位，左右两屏 `left: ±100%`，中间屏留流内撑高。屏宽严格等于轨道宽，不再经过 flex 分配。

弯路：第一轮以为是 `flex-shrink` 压缩了三屏，把 `flex: 1 0 100%` 改成 `flex: 0 0 100%`，编译通过但真机复测仍然重叠。shrink 不是根因，不要在这条路上反复试。

### 2. 屏宽兜底估算偏小

现象：测量回调返回之前就开始拖动，落定位置差一点。

根因：估算公式把页面左右内边距算成了四份，`(12 * 4 + 68) / 750 * w`，实际只该算两份，页面 `padding` 左右各 12rpx。

处理：改成 `w - (24 + 68) / 750 * w`。固定列 68rpx，页面左右内边距共 24rpx。

### 3. 绝对定位之后坐标没跟着改

现象：改完 wxml 与 wxss，翻周方向反了，或者拖到一半就卡住。

根因：js 里的平移基准还是 flex 方案的 `-paneW`，而绝对定位后本周就在 0 位。

处理：四处一起改，初始渲染、测量回调、手势起点兜底、落定位。坐标系是居中 0、上周 +paneW、下周 -paneW、回弹 0、钳制 ±paneW。只改其中一两处，会出现首屏对但拖动错位的情况。

### 4. 落定后画面闪一下

现象：松手翻周，动画结束时内容跳一下。

根因：先归零再换数据，中间有一帧是旧内容停在 0 位。

处理：换数据与归零写在同一次 `setData`。新的上一周此刻正好在 `left: -100%`，本周在 0 位，内容和坐标同时换，肉眼看不到跳。

### 5. 动画没播完又去拖，卡死

现象：快速连翻两次，第二次滑动不跟手，页面像冻住。

根因：上一次落定的定时器还在跑，结束时会把 `trackX` 强行写成 0，覆盖了新的拖动位置。

处理：`onTouchStart` 先清待落定定时器，把当前 `trackX` 记成新的 `_baseX`，关过渡后接管跟手。定时器句柄存实例字段，`onUnload` 里一并清掉。

### 6. 拖完松手，误弹出课程详情

现象：横向拖动之后，手指抬起的位置触发了一次点按。

处理：手势判定为横向时把 `_moved` 置真，`onLessonTap` 与 `onCellTap` 入口先看这个标记，为真直接返回。

## 二 样式与交互

### 7. 自造按压类，越加越多

现象：不同页面各写一套 hover 样式，同样是按钮，有的压透明度，有的换底色，有的加缩放。

处理：收敛成五档，`tap-press`、`tap-row`、`tap-accent`、`press-brand`、`press-red`，全部定义在 `app.wxss`。页面只允许引用这五个值。旧类直接删掉，不留兼容。

注意：如果写了静态计数断言，wxml 里同一段模板被 `wx:for` 循环三次，字符串只出现一次，计数按静态出现次数算，不是按运行时实例数。

### 8. 主按钮按压后白字发灰

现象：绿色主按钮按下时，文字也跟着变透明，像禁用态。

处理：主按钮改用实底加深，`#285E4D`，不给容器压透明度。危险操作单独一档，红色渐变。

### 9. 图标风格割裂

现象：同一页五个图标，有的实心红，有的细线，有的填色块，摆在一起像五个人画的。

处理：统一 3rpx 描边、圆角端点、品牌绿或 `currentColor`，主体控制在 24 网格居中。番茄钟的实心红改成红色描边轮廓，保留识别色但不破坏线性统一。待开发占位保持灰色，不抢主图标。

### 10. 图标用字符拼

现象：星标用 `★`，删除用 `×`，不同机型字体不同，大小和基线全乱。

处理：星标做成两张位图，空心与实心各一张，81×81 超采样后使用。删除叉用 view 拼两条线。所有图标不用 emoji。

### 11. 热区不够

现象：星标、删除叉这类小图标点不准。

处理：可点元素外层不小于 88rpx，图标本身可以小，外层撑开。跨平台对照 44pt 的规则，小程序按 rpx 折算取 88。

### 12. 异步按钮连点

现象：导入、识别这类操作，手指连点两下执行两次，弹两次提示。

处理：进入异步先置 `loading`，按钮挂 `disabled` 并换文案，回调结束再恢复。

### 13. 删除没有退路

现象：倒计时、番茄钟的删除点一下就没了。

现状：这一版仍是即时删除。要补二次确认或撤销提示，属于未完成项。

## 三 能力与环境

### 14. 端侧 OCR 在真机完全不回调

现象：VisionKit 的 VKSession 在真机上没有任何回调，30 秒后超时。

处理：不修引擎，降级到手动录入，提示文案写清"识别没成功，可以粘贴或手录"。云 OCR 与纯本地的口径冲突，没有采用。

### 15. 开发者工具模拟器白屏

现象：改完代码，模拟器一片白。

根因：模拟器的渲染缓存没刷新，不是代码问题。

处理：真机验证为准，不要因为模拟器白屏去改代码。

### 16. 预览二维码打不通

现象：命令行预览报 IDE port timeout，GUI 报 NO_SESSION，没有上传私钥。

处理：这条路走不通，改用真机调试或直接上传体验版，不要把时间花在打通 CLI 上。

### 17. Skyline 与 worklet 拖拽

现象：想用 Skyline 的 worklet 做拖拽排序，兼容性和表现都不稳。

处理：退回普通 touch 事件加 CSS transform。本地优先的方案里不引入这类新渲染引擎。

### 18. wcsc 编译 app.wxss 失败

现象：`@import "styles/vars.wxss"` 在 wcsc 里解析不到。

处理：各页 wxss 可以正常编译，只有 `app.wxss` 这一层不行，靠人工核对变量名是否存在。别为了让它编译通过把变量拆散到各页，那样色板就散了。

### 19. 写文件把编码写坏

现象：脚本生成的小程序源码出现乱码或开头多出 BOM，编译报非法字符。

处理：统一 UTF-8 无 BOM、`newline=""`，路径用绝对路径。PowerShell 的重定向和默认编码会改字节，复杂写入交给 Python 脚本，脚本里显式指定编码。

## 四 数据

### 20. 存储结构变更没有迁移

现象：改了存储字段名，老用户打开后数据空。

处理：存储键固定 `ct-state-v1`，读取时给缺省值兜底，版本号变化时写迁移函数，不要直接换键名把老数据丢掉。

### 21. 底部固定栏遮住最后一行

现象：课表最后两节被底部操作栏压住。

处理：页面 `padding-bottom` 给到 132rpx，空态没有底栏时单独收窄到 40rpx。

### 22. 发布前混进真实数据

现象：`.json` 导出文件、截图、原始表格和源码放在同一层目录，打包或提交时容易一起带走。

处理：数据文件与源码分目录；发布仓库里放虚构示例，字段结构一致；`.gitignore` 排掉 `*.xls`、`*.xlsx`、`*.csv` 和本地私有配置。提交前跑一遍关键词扫描，确认没有校名、班级名、教师姓名、校内文号。
